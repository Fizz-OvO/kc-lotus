1. 構成コンセプト（ネオン＋チェンバー構成）

  • Karmine Corp Lotus comp（ネオン＋チェンバー構成）
  • LewN = Neon（ネオン）／ N4RRATE = Chamber（チェンバー）／ Avez = Fade（フェード）／ dos9 = Omen（オーメン）／ SUYGETSU = Viper（ヴァイパー）
  • 1デュエリスト＋1センチネル＋1イニシエーター＋2コントローラーの構成。EMEA Stage 2 2026で使われた全6試合・125ラウンドが対象で、6試合すべて同一構成。Champions 2026ではKCはロータスを使用していない（使用マップはSunset／Abyss／Ascent／Summit／Haven）
  • 戦績は5勝1敗（唯一の敗戦は決勝のTeam Liquid戦 7-13）、ラウンドは 74勝51敗（59.2%）。攻撃 47勝27敗（63.5%） ／ 防衛 27勝24敗（52.9%）と攻撃側が強い構成
  • 数値出典: vlr.gg＋vreplay映像解析（勝敗は全125ラウンドでvlrと一致を検証済み）。GIFは124ラウンド分あり（Team Liquid戦R18は検出漏れでGIFなし・勝敗と勝因メモのみ）

強み

  • 起点はNeonではなくChamberのFB
  • → FB取得64ラウンドの内訳は N4RRATE（Chamber）28回・dos9 12回・LewN 10回・SUYGETSU 8回・Avez 3回。エントリー役のLewNより、N4RRATEのピックがこの構成の最大の起点
  • → FBを取ったラウンドは 54勝10敗（84.4%）と、取れればほぼ勝てる
  • A攻めと設置後の取り切り
  • → 攻撃74ラウンド中57ラウンド（77%）で設置に成功し、設置ラウンドは 44勝13敗。本命のAは主戦場35ラウンド・設置25回で、設置後は 21勝4敗（84.0%）と非常に堅い
  • ULT合わせとラッシュが必勝パターン
  • → 勝因判定にULTを含む攻撃ラウンドは 14ラウンド、ラッシュ判定の攻撃ラウンドは 8ラウンド。各セクションに勝敗を掲載（ULT 13勝1敗／ラッシュ 8勝0敗）
  • リテイク防衛が全勝
  • → 勝因判定で「リテイク」とされた防衛ラウンドは18ラウンド全勝。サイトを明け渡してから人数を揃えて取り返す形が完成しており、A防衛の弱さを補っている

弱み

  • FBを落とすと勝率が急落する
  • → FBを落としたラウンドは 20勝40敗（33.3%、60ラウンド）。取れた時（84.4%）との落差がそのままこの構成の勝敗ライン。唯一負けた決勝（Team Liquid戦）は防衛が 2勝6敗まで崩れた
  • Aサイトを守り切れない
  • → 防衛で主戦場がAになったラウンドは 9勝13敗（40.9%）。AアンカーのAvezが落とされると守り切れず、勝ち筋がリテイク依存になっている
  • B設置が一番弱い
  • → B設置は 10勝5敗（66.7%、15回）で、A（84.0%）・C（76.5%）より低い。Bを選ぶ頻度自体も3サイトで最少
  • ピストルは防衛偏重
  • → ピストルラウンドは 8勝4敗（攻撃 3勝3敗／防衛 5勝1敗）

防衛の配置（実測）

  • 両アンカーがほぼ固定（実測）
  • → 防衛51ラウンドの開始時点（1:40）の検出ベース実測
  • → Avez（Fade）: A 45回／B 2回（n=47）と、ほぼ完全にAアンカー固定
  • → dos9（Omen）: C 34回／A 7回／B 2回（n=44）でCアンカーが基本
  • 残り3人はフレックス（実測）
  • → SUYGETSU（Viper）: B 14回／C 15回／A 9回（n=39）とB-C間のフレックス
  • → LewN（Neon）: A 19回／B 11回／C 11回（n=41）と全域を動く
  • → N4RRATE（Chamber）: A 14回／C 12回／B 4回（n=30）と検出数自体が少なく、サイト外のピック位置にいることが多い
  • → ※ 図解はTactiValで後日追加

攻撃の形（実測）

  • A本命＋Cサブ、Bは最少
  • → 主戦場はA 35ラウンド・C 22ラウンド・B 16ラウンド、設置もA 25回・C 17回・B 15回
  • → 設置後の勝率はA 84.0%／C 76.5%／B 66.7%の順で、攻め先と守り切りやすさが一致している
  • 攻撃の初期配置は実測不可
  • → 放送ミニマップの仕様で攻撃側の選手アイコンが表示されず、選手単位の初期配置は測定できない。デフォルトの形はGIFの動きからの推定になるため、ここでは断定しない
